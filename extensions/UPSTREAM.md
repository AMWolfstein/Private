# Upstream provenance and native maintenance

Artwork reference repository: https://github.com/mornyeapp/Mornye-Extension
Reference revision: `12530ceda46dc78a10f9258b7d65a71452dfcf50`.

`upstream-lock.json` retains the historical source versions and hashes of the
thirteen selected artwork sources. These are provenance records, not an inventory
of installed providers or local executable JavaScript. Jellyfin remains excluded.
The inactive JavaScript copies and extraction tools have been removed; their final
historical copy is commit `cb7c06e14f38730306da7010af991f6474f6f0df`, preserved on
`extension-system`. Licences and NOTICE remain with the derived native code.

Apple/Deezer golden fixtures were produced from that pinned reference before
removal. Native tests still compare their artwork/editorial outputs against those
fixtures. Fixture regeneration requires a separate checkout of the historical
commit and its development oracle; it is not an application runtime or a step in
the current source-review workflow. See `artwork/README.md`.

For future updates, inspect the review-only diffs generated by `updates/`. Compare
applicable upstream behavior and authentication changes against the native code,
update native characterization/failure tests, and adapt Rust or the documented
bounded JSON settings as needed. Never restore a downloaded JavaScript runtime or
import source automatically. Review licence changes, including the upstream
K-Music redistribution-permission explanation dated 2026-11-06, before new ports.

The separate `lyrics/origin-lock.json` records this application's original Rust
lyric sources. Those implementations were retained, not replaced by the removed
CommonJS copies. Review proposals and implemented-source provenance are separate:
merging a report must not claim that a provider has been ported or updated.
